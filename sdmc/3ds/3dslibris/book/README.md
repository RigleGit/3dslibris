# User Books

Place your ebooks in this directory.

```text
sdmc:/3ds/3dslibris/book/
```

Bundled with template/releases:
- `QuickStart.txt` (basic controls and feature overview)

You can delete `QuickStart.txt` and this README from your SD books directory.
Restart the app afterwards; bundled copies will not reappear while that
directory exists. An empty directory shows `No books found`.

Supported extensions:
- `.epub`
- `.fb2`
- `.txt`
- `.rtf`
- `.odt`
- `.mobi`
- `.pdf`
- `.xps`
- `.oxps`
- `.cbz`
